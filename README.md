# ☕ Sip & Savor — Coffee Shop Website

A modern, responsive coffee shop website designed to bring the café experience online. Sip & Savor features an inviting interface where customers can explore the menu, discover the café, and access account and reservation pages.

Built using HTML, CSS, and JavaScript, the project focuses on responsive design, intuitive navigation, and an engaging user experience.

## ✨ Features

- **Responsive Design** — Adaptable layout for desktop, tablet, and mobile screens.
- **Interactive Menu** — Browse coffee selections and explore the café's offerings.
- **Login & Signup Interface** — Dedicated page for the user authentication experience.
- **Table Reservations** — Interface for collecting customer reservation details.
- **Modern UI** — Café-inspired visuals, typography, and styling.
- **JavaScript Interactions** — Dynamic frontend behaviour and navigation.
- **Cross-Browser Compatibility** — Designed to work across modern web browsers.

*Note: Authentication, reservation storage, and database functionality require a working backend. List these as implemented features only after they have been tested.*

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension for convenient local development

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Sip-Savor.git
```

**2. Navigate to the project directory**

```bash
cd Sip-Savor
```

**3. Run the website**

Open `index.html` directly in your browser, or open the project in VS Code and use the Live Server extension.

The frontend does not require `npm install` unless a Node.js backend or additional npm dependencies are included.

### Backend Setup

If the project includes a Node.js and Express backend with a `server.js` entry point:

```bash
npm install
node server.js
```

Configure your MySQL connection using environment variables before starting the backend. The server command and local URL depend on the actual backend implementation.
